# Content Guidelines (объяснения и темы)

## Как писать объяснение к вопросу (шаблон)
1) Коротко: “Почему правильный ответ такой”
2) Типичная ошибка: “Почему люди путаются”
3) Запоминалка/правило: короткая эвристика
4) Источник: тема/пункт (если есть в базе rules)

## Тон
- простым языком
- без занудства
- короткими абзацами
- без “воды”, только по делу

## Формат полей (рекомендация)
- explanation_short: 1–2 абзаца
- explanation_full: до 600–900 символов
- common_mistake: 1 абзац
- mnemonic: 1 строка

## Контент в репо
- content/rules/: правила/темы (md/json)
- content/explanations/: объяснения к вопросам (md/json)
