# MVP Scope (Navio)

## Must (обязательно в релиз)
- Auth: регистрация/вход (email + пароль), сессия
- Тренировка:
  - выдача вопроса (random)
  - ответ -> правильно/неправильно
  - пояснение (из базы)
  - следующий вопрос
- Ошибки:
  - список ошибок
  - повтор “только ошибки”
- Экзамен:
  - старт экзамена (20 вопросов)
  - прохождение
  - результат + список ошибок
- Прогресс:
  - базовая статистика (правильно/неправильно)
  - слабые темы (по простому счётчику)
- AI (MVP без генерации):
  - “Объясни ошибку” на основе: редакционного объяснения + привязанных тем/правил
- Web:
  - лендинг
  - веб-тренажёр (минимум: тренировка + экзамен)
- Юридическое/служебное:
  - Privacy Policy + Terms
  - “Источники/актуальность” (страница/раздел)
  - отчёт об ошибке вопроса

## Should (желательно в MVP, если успеваем)
- Умная выдача (smart training): больше вопросов по слабым темам
- Фильтры ошибок по темам
- SEO-страницы тем (минимальный набор)
- Оффлайн кеш (мобилка: последние N вопросов/картинок)

## Could (после MVP)
- Кабинет преподавателя + конструктор тестов
- Уроки (текст + “шорты”) и привязка к ошибкам
- Подписка Pro
- Пуши / streak / геймификация
- iOS релиз (если MVP стартует с Android)
