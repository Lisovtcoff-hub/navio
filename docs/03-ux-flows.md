# UX Flows (MVP)

## Сущности (для понимания UX)
- Вопрос: текст + (картинка) + варианты
- Тема: группировка вопросов (перекрёстки, знаки, разметка)
- Попытка: ответ пользователя
- Экзамен: сессия из 20 вопросов

## Онбординг
1) Welcome
2) Signup/Login
3) (опционально) выбор цели: “учить” / “скоро экзамен”
4) Home

## Тренировка
Home -> Training (вопрос)
- выбрать вариант -> подтвердить
- результат (правильно/неправильно)
- показать короткое пояснение
- кнопки: Следующий | Объясни (ассистент)
- долгий тап/кнопка: “в избранное/в ошибки” (позже)

## Ошибки
Home -> Mistakes list
- фильтр по темам (should)
- открыть вопрос -> повторить -> пояснение -> следующий

## Экзамен
Home -> Start Exam
- экран правил: 20 вопросов, таймер (если в MVP), ошибки
- проход
- finish -> результат
- “план на повтор”: список тем/ошибок

## Прогресс
Home -> Progress
- статистика: решено, правильных, ошибок
- слабые темы (топ-5)
- кнопка “тренировать слабые” (should)
