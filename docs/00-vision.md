# Navio — Vision

## Коротко (1 предложение)
Navio — тренажёр ПДД РФ: адаптивная тренировка + экзамен как в ГИБДД + понятные объяснения и ассистент, который отвечает строго по источникам.

## Для кого
- Ученики автошкол и самоподготовка (категория B в MVP)
- Преподаватели/автошколы (кабинет + задания + аналитика)

## Проблема
Существующие приложения часто сводятся к “натаскиванию на билеты”, дают мало понимания и плохо ведут по слабым темам.

## Почему Navio будет лучше
- Адаптивная тренировка: больше вопросов по слабым темам и повторение ошибок
- Разбор ошибок “как инструктор”: простым языком + ссылки на правила/темы
- Доверие: ассистент не фантазирует — только опора на базу знаний/контент
- Сильная траектория: видно прогресс и “что учить дальше”

## Тон бренда
Дружелюбно, уверенно, без занудства. Маскот: капибара (спокойствие и уверенность).

## Северная звезда (North Star Metric)
Пользователь стабильно “сдаёт” симулятор экзамена (например: 3 успешных экзамена подряд) и достигает высокой освоенности тем.

## Успех MVP
- Выпущены Android + Web
- Пользователь может: тренироваться, сдавать экзамен, смотреть ошибки/прогресс
- Есть базовый ассистент “объясни ошибку” (без галлюцинаций)
- Собран фидбек (первые 50–200 пользователей)
