# Release Checklists (MVP)

## Android — Google Play
- [ ] Уникальный package name
- [ ] Версии: versionCode/versionName
- [ ] App icon (512x512) + adaptive icon
- [ ] Feature graphic
- [ ] 5–8 скриншотов
- [ ] Короткое/полное описание
- [ ] Privacy Policy URL
- [ ] Data Safety form
- [ ] Internal testing -> Production
- [ ] Проверка deep links (если есть)

## Web
- [ ] Домен + SSL
- [ ] robots.txt, sitemap.xml (если есть SEO)
- [ ] 404/500 страницы
- [ ] Аналитика событий
- [ ] Sentry

## Backend
- [ ] ENV secrets не в репо
- [ ] Логи + Sentry
- [ ] Бэкапы Postgres (минимально)
- [ ] Rate limiting (опционально)
